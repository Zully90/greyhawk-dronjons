# Greyhawk Campaign Tools

Strumenti web per la campagna Greyhawk (PF2e) di Marcello.
Hostato su GitHub Pages. Zero dipendenze, zero build system.

## Pagine

| File | Descrizione | Stato |
|------|-------------|-------|
| `index.html` | Artiglio del Collezionista di Sospiri — tracker interattivo | ✅ Completo |
| `spawn.html` | Sistema spawn spiriti al calar del sole | 🚧 In costruzione |

## Sviluppo locale

Apri qualsiasi file `.html` direttamente nel browser. Non serve un server.

## Deploy

GitHub Pages: Settings → Pages → Branch: main → Save.
